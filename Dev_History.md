# 🗄️ Архив версий — RGG Land Chat Overlay

История userscript'а по версиям. Каждый файл в этой папке — **самодостаточный** `.user.js`,
который можно установить в Tampermonkey независимо от остальных (это снимки состояния прибора
на момент релиза, а не патчи). Текущий релиз живёт в корне репозитория; здесь — музей.

> Файлы названы по бейджу, который горит в шапке чата у соответствующей версии
> (`vNN` на первом мониторе, `vNN·wall` на стене).

## Структура

```
history/
├── README.md
├── rgg-chat-v10.user.js
├── rgg-chat-v11.user.js
├── ...
└── rgg-chat-v20.user.js
```

## Дуга разработки

| Версия | Суть одним предложением |
|---|---|
| **v10** | Крестик больше не убивает окно: скрытие + якорь-возврат + `Alt+C` + память состояния «был скрыт». |
| **v11** | Режим второго монитора `#chatwall` + master/slave-связь через `localStorage` и событие `storage`. |
| **v12** | Мастер транслирует активного **всегда** (не только при `AUTO`) + heartbeat-пульс + индикатор `LINK / NO LINK`. |
| **v13** | Рубильник якоря (кнопка-булавка) с памятью; якорь можно убрать совсем, возвращать чат через `Alt+C`. |
| **v14** | Фикс: стена больше не стартует скрытой из-за общего с первым окном флага `hidden`. |
| **v15** | Режим «листочек сайта»: по кнопке чата плеера наш чат встаёт в правую колонку вместо родного (без перехвата кликов). |
| **v16** | Фикс слепоты первого окна (режим листочка больше не прячет чат наглухо) + guards на навешивание кнопок. |
| **v17** | **Watchdog**: пересоздаёт чат, если сайт вынес его из DOM (фикс пропажи после `Ctrl+F5`) + самоочистка от двойного инжекта + `try/catch`. |
| **v18** | Кнопка `WALL` открывает стену **отдельным окном** через `window.open` — без ключей запуска и ярлыков, во всех браузерах; окно само помнит позицию; в режиме листочка `S/M/L` меняются на `WALL`. |
| **v19** | Фикс: выход из режима листочка больше не прячет плавающий чат (сброс застрявшего `hidden`). |
| **v20** | Аварийный маркер-невидимка в углу — возврат, когда якорь выключен; закрыта ловушка «скрыл + фокус в плеере → не вернуть». |
| **v21** | *(текущий релиз, в корне репо)* «Тихий релиз»: булавка удалена, маркер — единственный невыключаемый возврат; чипы только в стене. |
