## 🛡️ v17.0.0 — «Бессмертный чат»

> Один userscript, который ложится **поверх чужого сайта** `rgg.land/live` и превращает сетку стримов в личный кокпит: плавающий чат на первом мониторе, чат-стена во весь рост на втором, и подмена родного чата сайта нашим — по той самой кнопке-«листочку». Без серверов, без сборки, без единой строчки доступа к исходникам сайта.

Этот релиз — про **живучесть**. Сайт rgg.land со временем копит пинг и лечится перезагрузкой, а перезагрузка раньше выносила чат из DOM и оставляла пустоту, которую оживлял только полный рестарт браузера. Теперь чат **дежурит сам**: сторож каждые две секунды проверяет, на месте ли он, и если сайт при своей пересборке выдернул узел — молча пересоздаёт его поверх живого состояния. `Ctrl+F5` больше не конец света.

---

### 🔥 Главное в этом релизе

**Сторож (watchdog) и самовосстановление.** Если сайт вынес панель чата или якорь из документа — скрипт это видит и пересобирает DOM на лету, не теряя ни геометрии, ни настроек, ни текущего стримера. Пустота теперь живёт максимум пару секунд и чинится без твоего участия.

**Самоочистка от двойного инжекта.** При «тёплой» перезагрузке Tampermonkey иногда запускает скрипт дважды, и два экземпляра дрались за один DOM. Теперь каждый новый запуск сначала аккуратно усыпляет предыдущий — снимает его таймеры, слушатели клавиш и висящие узлы — и только потом строит свой. Никаких дублей и зависших интервалов из прошлой жизни страницы.

**Обёртки `try/catch` вокруг старта и тика.** Одно случайное исключение в странной фазе перезагрузки больше не убивает скрипт молча: ошибка ловится, пишется в консоль с префиксом `[RGG-chat]`, а сторож всё равно поднимет чат следующей итерацией. Слепота, в которую можно было попасть раньше, стала конструктивно невозможна.

### 🧩 Что умеет прибор (полный набор)

**Плавающий чат-оверлей** — сам определяет активного стримера по геометрии (самый большой видимый плеер) и переключает чат вслед за ним; стабилизация от мерцания, дедупликация каналов, алфавитная лента чипов.

**Принудительная тёмная тема** — Twitch-embed в последних версиях игнорирует `darkpopout`/`theme=dark`, поэтому чат перекрашивается CSS-фильтром `invert + hue-rotate`: чёрный фон, светлый текст, цветные ники и эмодзи на месте. Тумблер `◐` выключает инверсию одним кликом, если нативная тема вдруг сама станет тёмной.

**Ресайз и пресеты** — тяни за любой край или угол (window-слушатели, не слетают), либо жми `S / M / L`; активный пресет подсвечивается фиолетовым, при ручном ресайзе подсветка гаснет.

**Память между сессиями** — позиция, размер, состояние инверсии, скрытость и все рубильники пишутся в `localStorage` и восстанавливаются при загрузке.

**Якорь-возврат вместо убийственного крестика** — `×` больше не уничтожает окно, а прячет его; в углу появляется пульсирующая кнопка-якорь с ником текущего стримера, возвращающая чат одним кликом. Рубильник-булавка убирает якорь совсем, когда он не нужен, — возвращать чат тогда можно горячей клавишей.

**Режим второго монитора (`#chatwall`)** — ярлык с `--app=` открывает сайт без вкладок во весь экран, сайт прячется, чат разворачивается на всю стену. Синхронизация со стрим-окном идёт через `localStorage` + событие `storage` + heartbeat-пульс: переключил стримера на первом мониторе — стена перелетает сама. Индикатор **LINK / NO LINK** в шапке стены в реальном времени показывает, жива ли связь.

**Режим «листочек сайта»** — по клику на родную кнопку чата в панели плеера сайт сдвигает свой layout, а в освободившуюся правую колонку во всю высоту встаёт **наш** чат; родной делается прозрачным (не `display:none`, чтобы layout не прыгал). Закрываешь листочком — наш чат прячется, плавающий возвращается. Перехват чужих кликов не используется намеренно — плеер, громкость и настройки сайта не трогаются вообще.

**Живая оболочка** — пульсирующий `LIVE`, бегущий блик на активном чипе, светящаяся рамка, пружинящие кнопки, тёмный лоадер со спиннером вместо белой вспышки; шрифты *Chakra Petch* + *Rubik*, палитра в цветах Twitch.

### ⌨️ Горячие клавиши и элементы управления

| Действие | Как |
|---|---|
| Скрыть / показать плавающий чат | `Alt + C` |
| Вкл/выкл режим «листочек сайта» | `Alt + D` |
| Авто-переключение / синхронизация | кнопка `AUTO` |

| Тёмная тема (инверсия) | кнопка `◐` |
| Якорь возврата (рубильник) | кнопка-булавка |
| Пресеты размера | `S` · `M` · `L` |
| Перезагрузить чат | `↻` |
| Переместить окно | тянуть за шапку |
| Изменить размер | тянуть за край / угол |

### 🖥️ Второй монитор: ключи запуска по браузерам

Режим стены работает в любом Chromium-браузере через флаг `--app=`. Путь к `.exe` всегда бери из `chrome://version` → *«Исполняемый файл»* (установки бывают системные и пользовательские — не гадай).

| Браузер | Флаг app-режима | Позиция окна через CLI |
|---|---|---|
| Chrome / Edge / Brave / Vivaldi / Яндекс | ✅ `--app=URL` | ✅ `--window-position` |
| Opera / Opera GX | ✅ `--app=URL` | ✅ (иногда нужен `--user-data-dir`) |
| Arc | ✅ `--app=URL` | ⚠️ профиль лучше не трогать |
| Firefox | ❌ только `-kiosk` | ❌ позицию не задать |
| Safari | ❌ нет CLI app-режима | — |
